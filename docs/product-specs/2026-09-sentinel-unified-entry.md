# SENTINEL 통합 명령과 선택형 언어 검사기

결론: 사용자는 하나의 명령으로 설정된 프로젝트를 검사하고, 언어별 검사기는 필요한 것만 독립 설치·갱신한다.

## 승인 근거와 기존 요구사항의 관계

사용자가 2026-09-08에 “3번으로 확정하고 진행해”라고 승인했다. 선택지는 언어별 완전 분리, 전체 도구 일괄 배포, 통합 명령과 선택형 검사기였다. 세 번째 방식이 확정됐다. 기존 55개 요구사항과 여섯 저장소를 폐기하지 않고 새 `SENTINEL` 구성요소를 추가한다. 기존 공통규칙-01의 여섯 저장소는 필수 구성 목록으로 유지하며 추가 구성요소를 금지하는 의미로 해석하지 않는다. 원격 저장소 생성·공개 배포·기존 backend 기본값 전환은 이 승인의 자동 결과가 아니다.

## 단계별 완료의 의미

첫 구현은 **로컬 통합 실행 기반**이다. tool bundle은 사용자가 명시한 로컬 디렉터리와 SHA-256으로 설치한다. 자동 다운로드, 패키지 검색, 모든 SDK 일괄 설치는 하지 않는다. SHA-256은 파일 내용이 달라졌는지 확인하는 값이며 게시자의 신뢰나 보안 격리를 증명하지 않는다.

기존 언어 CLI의 입력·출력과 준비 수준이 서로 다르므로, 실행 계약 시험용 bundle을 실제 언어 품질 검사 완료의 증거로 사용하지 않는다. 정식 admission(운영 투입 허용) 전 bundle은 experimental로만 허용한다. 이 상태의 실행은 관측 결과를 보여주되 `certified=false`, 품질 인증 성공 종료를 내지 않는다. 정식 native bundle, 실제 프로젝트 비교, 격리 승인, host 설치 활성화가 모두 끝나야 통합 제품 완료다.
