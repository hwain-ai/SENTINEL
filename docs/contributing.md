# 기여 안내

SENTINEL의 오류 제보와 문서·코드 수정 제안을 받습니다. 사용법은 [README](../README.md)에서 확인하세요.

## 문제를 발견했다면

[Issues](https://github.com/hwain-ai/SENTINEL/issues)에서 같은 문제가 등록되어 있는지 찾아보고, 없다면 새 글을 작성해 주세요. Issues는 오류를 제보하거나 기능을 제안하는 게시판입니다.

오류를 제보할 때는 다음 내용을 적어 주세요.

- 사용한 운영체제와 SENTINEL 버전
- 실행한 명령이나 Claude Code·Codex에 입력한 요청
- 기대한 결과와 실제 결과, 화면에 나온 오류 메시지
- 같은 문제를 다시 확인할 수 있는 최소한의 코드와 테스트 파일

문서가 이해되지 않았다면 문서 링크와 막힌 부분만 알려 주셔도 됩니다. 새 기능을 제안할 때는 어떤 작업에서 필요했는지 함께 적어 주세요.

## 문서나 코드를 고치려면

1. GitHub의 **Fork** 버튼으로 이 저장소를 본인 계정에 복사합니다.
2. 복사한 저장소에서 파일을 수정합니다. 오타는 GitHub에서 해당 파일을 열고 연필 버튼으로 바로 고쳐도 됩니다. 코드를 수정할 때는 [개발 안내](development.md)의 준비·테스트 절차를 따르세요.
3. 문서를 수정했다면 링크와 예시를 확인합니다. 코드를 수정했다면 테스트를 실행하고, 사용법이나 출력이 바뀐 부분의 설명도 고칩니다.
4. 원본 저장소에 **Pull request(PR)**를 보냅니다. PR은 “이 변경을 프로젝트에 반영해 주세요”라는 수정 제안입니다. 무엇이 문제였는지, 무엇을 고쳤는지, 어떻게 확인했는지 적어 주세요.

개발 환경 준비, 테스트 명령, 문서 검사에서 실패했을 때의 해결 방법은 [개발 안내](development.md)에 있습니다.
