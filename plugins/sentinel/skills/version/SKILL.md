# 버전과 설치 상태 확인

`sentinel --version`은 실행기 버전 번호, `sentinel version`은 프로젝트의 도구 설치 상태를 확인한다. 실행기 0.4.0 이상을 사용한다.

1. 현재 호스트의 설치된 플러그인 정보 또는 설치된 plugin.json에서 플러그인 버전을 읽고, 확인한 실행기에 `--version`을 전달해 실행기 버전을 확인한다.
2. 프로젝트의 `sentinel.workspace.json`에서 언어별 모듈·toolVersion을 읽는다. 동일한 프로젝트·설정·도구 경로로 `sentinel version`을 실행해 설치 파일·지문·승인 상태를 확인한다.
3. 구성, 설치 버전, 설치 상태, 승인 여부와 경로를 표로 보고한다. 실행기 버전, 플러그인 버전, 언어 어댑터 버전은 서로 다른 번호다. 원본 mutmut·Stryker·SDK 버전까지 요청하면 확인된 언어 소스의 잠금 파일을 읽고, 잠금 파일 값과 직접 실행해 확인한 버전을 구분한다.
4. 설치나 설정이 없으면 없는 상태로 보고한다. 자동 설치·업데이트·원격 갱신·품질 검사·코드 수정을 하지 않는다. `ready`는 설치 확인이며 품질 통과가 아니다.
