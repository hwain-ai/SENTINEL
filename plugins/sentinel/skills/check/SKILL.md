# 점수 확인

[측정 지침](../sentinel/references/measurement.md)을 읽는다. `check`는 기본 스킬의 반복 수정 동작보다 우선하는 측정 전용 요청이다.

1. 요청한 기능 파일·함수와 관련 테스트를 확인한다. 지정이 없으면 설정된 전체 범위를 검사한다. 사용자가 지정한 기준이 없으면 기존 프로젝트 기준을 쓴다.
2. 확인한 SENTINEL 실행기로 검사한다. 실행기가 없거나 준비가 안 됐으면 필요한 `start` 작업을 안내한다. 별도 설치 요청 없이 설치나 설정 변경으로 범위를 늘리지 않는다.
3. 범위, CRAP·mutation 점수와 기준, 통과 여부, 파일·함수·변이 위치를 보고한다. 기능 코드·테스트·판정 기준을 바꾸거나 실패를 고쳐서 재검사하지 않는다. 검사기가 생성하는 측정 기록은 정상 검사 출력이다.
4. `noChanges`는 미검사, 실행 오류와 미측정은 그대로 보고한다. 결과를 통과시키려면 기본 `sentinel` 스킬을 사용한다고 안내한다.
