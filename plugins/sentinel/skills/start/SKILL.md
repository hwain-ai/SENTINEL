# SENTINEL 시작

`/sentinel:start` 또는 `$sentinel:start`는 설치·초기 설정 요청이다. [공통 설치 절차](../sentinel/references/setup.md)를 읽고 현재 프로젝트에서 준비를 마친다.

1. 현재 프로젝트, 사용 언어, 소스·테스트 폴더와 기존 SENTINEL 설치를 확인한다. 확인할 수 없는 경로나 여러 후보 중 선택해야 할 사항만 묻는다. `start`로 요청한 설치에 대해 같은 동의를 다시 묻지 않는다.
2. 실행기와 필요한 언어 도구가 없으면 공식 설치 절차로 준비한다. Linux·macOS에서는 직접, Windows에서는 확인한 WSL 환경에서 실행한다. 설치된 도구와 기존 설정은 재사용한다.
3. 새 프로젝트의 기본 기준은 CRAP 8 이하·mutation 90% 이상으로 설정한다. 기존 기준 또는 사용자가 명시한 기준은 유지한다. 기능 코드·테스트 범위를 실제 프로젝트에 맞추고 필요한 언어를 명시해 `setup`을 실행한다.
4. `plan`으로 설정된 범위를, `version`으로 도구 설치와 승인 상태를 확인한다. 문제를 해결할 수 없으면 진단과 필요한 입력을 보고한다.
5. 실행 환경·프로젝트·실행기 경로, 준비한 언어, 적용 기준, 준비 상태를 짧게 보고한다. `ready`는 설치 확인이며 품질 통과가 아니다. `start`만 요청했다면 여기서 끝낸다. 실제 검사·수정·재검사는 사용자가 함께 또는 이후에 요청한 범위에서 수행한다.
