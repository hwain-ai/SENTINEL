# 공식 배포판 업데이트

[갱신 절차](../sentinel/references/update.md)를 읽고 요청한 구성요소를 갱신한다. 사용자가 플러그인만·실행기만·특정 언어만 지정했으면 그 범위를 유지하며, 지정이 없으면 현재 설치된 SENTINEL 구성요소를 대상으로 한다. 다른 플러그인이나 사용하지 않는 언어를 추가하지 않는다.

업데이트 전후 버전·승인 상태와 재시작 필요 여부를 보고한다. 파일 수정 충돌이나 설치 오류는 그대로 알리고 기존 설정과 설치를 강제로 덮어쓰지 않는다. 실제 품질 검사와 수정은 별도 요청이 있을 때 수행한다.
